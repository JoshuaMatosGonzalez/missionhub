Mission Hub - standalone website
================================

Files
- mission-hub.html : the whole site in one file (styles, scripts and the globe image are built in)

How to view
- Double-click mission-hub.html to open it in any browser.

How to host or embed
- Upload mission-hub.html to your web server or SharePoint site.
- To embed it in another page, use:
  <iframe src="https://YOUR-SITE/mission-hub.html" width="100%" height="900" style="border:0"></iframe>

Not connected in this copy
- Mission SI (chat, Ask bar, Knowledge Center assistant) shows keyword matches instead of answers.
- Capability requests and feedback can't be saved until a database is connected.
- Follows and bookmarks are saved in each person's own browser.
- Fonts load from Google Fonts; if blocked, the site falls back to system fonts.

All tool details, partners, metrics and contacts are sample placeholders until owners confirm them.
